About

pkg.bot is a fast search engine for Linux packages across distributions and package repositories. It uses the package data dump from Repology and is updated once a week.

In early September 2026, I had just switched to NixOS. In the process of setting it up, I was frequently searching for packages on the official package site, but was quite annoyed by its clunky UX. No way to sort by date or versions, no "permalink" to share a package's page even.

I remembered that pretty much most distros have clunky, annoying package sites. So I built this. Any queries or contributions, please raise at @knadh/pkg.bot.

Features

  • Super-fast search, filtering, and querying
  • Good UX (subjective) and accessibility
  • Sort and filter across various parameters
  • Filter on recency, eg: version > 2.0 and updated > 2026-01-01
  • RSS feeds for search, filtering, and individual packages

API

API endpoints return JSON by default. Use repository and package slugs from their page URLs.

URL Description Query params
{{ consts.root_url }}/api/repos List of all repositories
  • family: Filter by repository family. Eg: nix, debuntu, arch
  • distro: Filter by distro. Eg: fedora
  • manager: Filter by package manager
{{ consts.root_url }}/api/repos/{repo} Details of a repository
{{ consts.root_url }}/api/repos/{repo}/packages List, search, and filter packages in a repository
  • q: String query for fulltext name+description+keyword search
  • name: Search package names and slugs only. Either use this or q but not both
  • license, tag, maintainer, group, platform
  • status: newest|outdated|ignored|unique|devel|legacy|incorrect|untrusted|noscheme|rolling|unprocessed. These are from Repology.
  • is_nonfree: true or false
  • version: Match a version (x, x.y, or x.y.z). Supports optional prefixes > or <
  • updated_at: Match updated date (YYYY-MM-DD). Supports optional prefixes > or <
{{ consts.root_url }}/api/repos/{repo}/{pkg} Details of a package

CLI

Search Linux packages from the terminal with a super simple Bash script

# Download the script and put it in your PATH
sudo wget -O /usr/local/bin/pkgbot https://github.com/knadh/pkg.bot/raw/refs/heads/master/scripts/pkgbot.sh

# Make executable
sudo chmod 755 /usr/local/bin/pkgbot

# Run!
pkgbot repos
pkgbot fedora_44 jq

LLMs

All API endpoints support pipe-separated CSV output easily ingestible by LLMs (and for formatting and directly displaying results on the terminal). Send Accept: text/csv to get a header row followed by the result rows.

curl -fsS -H "Accept: text/csv" {{ consts.root_url }}/api/repos

Piping it to column produces neatly formatted tabular output.

curl -fsS -H "Accept: text/csv" {{ consts.root_url }}/api/repos | column -t -s "|"
